3. What it does on your machine

So there are no surprises about what you are installing:

  • Runs a local web server on 127.0.0.1, reachable only from your own machine, and shows it in a native window.
  • Makes outbound requests to the public Fantasy Premier League API, and to the Gaffer account service if you sign in.
  • Writes a cache and your preferences to your user folder.
  • Does not run at startup, install background services, read files outside its own folder, or send telemetry.
